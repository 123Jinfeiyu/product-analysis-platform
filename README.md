# 商品分析平台

一个面向电商选品与商品数据分析的本地一体化工具。基于 **Django + Vue 3** 开发，用 **PyInstaller** 打包成免安装的 Windows 可执行程序，双击即用，数据全部保存在本地，不上传任何外部服务器。

---

## 功能概览

侧栏默认展示 4 个核心菜单，其余 6 项收在「显示全部功能」开关里（隐藏而非删除，状态会被记住）。

### 默认展示

| 模块 | 说明 |
| --- | --- |
| 分析看板 | 商品总量、价格区间、品牌/类目分布等概览指标与图表 |
| 商品管理 | 商品列表、多条件筛选（关键词/品牌/类目/状态/排序）、分页；支持 CSV / Excel 导入与模板下载 |
| 维度分析 | 按价格、品牌、类目等维度做分布与对比分析 |
| AI 助手 | 商品推荐、看板洞察、营销文案三类任务，支持多厂商切换 |

### 收在开关里（6 项）

| 模块 | 说明 |
| --- | --- |
| 数据采集 | 内置浏览器抓取唯品会商品数据，需登录唯品会账号 |
| 数据接口 | 对接外部商品 API（支持 GET/POST、多种鉴权方式、字段映射、数组路径探测） |
| 商品排行 | 按销量/价格/推荐分等维度排行 |
| 抓取记录 | 每次采集的关键词、耗时、获取/新增/更新条数、错误信息 |
| 来源管理 | 管理商品来源（关键词搜索 / 品牌馆 / 榜单 / 类目 / 商品详情） |
| 登录账号 | 管理采集用的第三方平台账号与登录状态 |

### AI 能力

- **DeepSeek** —— 已内置，开箱可用
- **通义千问 / 豆包** —— 在 AI 助手页点「设置」填入自己的 API Key

厂商的接口地址、模型名、Key、连通耗时与错误都会记录，便于排查。

## 快速开始

1. 下载本仓库后，**把整个「商品分析平台」文件夹一起解压**（不能只拖出 exe）。
   exe 依赖同目录下的 `_internal` 文件夹，缺了无法启动。
2. 双击 `商品分析平台.exe`。
3. 程序会在窗口里打印访问地址并自动打开浏览器：

   ```
   http://127.0.0.1:8848/
   ```

   > 启动窗口与日志中也会打印该地址，以实际输出为准。

4. 使用默认账号登录：

   ```
   账号：admin
   密码：admin888
   ```

5. **首次打开商品总数为 0、图表为空是正常的**。本程序是分析工具，不自带商品数据，需要先导入：
   - 方式一：商品管理 → 上传导入，选择 CSV / Excel（含「商品名称」列即可，品牌、类目、价格、原价、销量、库存、图片地址等列会自动识别），可用「下载模板」获取标准表头；
   - 方式二：显示全部功能 → 数据采集（浏览器抓取唯品会，需登录）；
   - 方式三：显示全部功能 → 数据接口（对接你自己的商品 API）。

## 技术架构

| 层次 | 技术 |
| --- | --- |
| 后端框架 | Django 6.1.2 |
| 数据库 | SQLite（本地单文件） |
| 前端 | Vue 3 + Element Plus + ECharts + Axios（均为本地静态资源，无 CDN 依赖） |
| 运行时 | Python 3.13（随包分发） |
| 打包 | PyInstaller（onedir 模式） |

前后端通过 JSON API 通信，前端为单页应用，服务端同时承担静态资源分发。

### 数据模型

| 模型 | 表名 | 说明 |
| --- | --- | --- |
| `Product` | `pc_product` | 商品主表：标题、品牌、类目、售价/原价/折扣、销量、库存、主图、链接、采集关键词、状态等，并对价格 / 品牌 / 关键词 / 来源+外部ID 建索引 |
| `Brand` | `pc_brand` | 商品品牌 |
| `Category` | `pc_category` | 商品类目（支持父子层级） |
| `ProductSource` | `pc_source` | 商品来源，含来源类型与接口配置 |
| `CrawlAccount` | `pc_account` | 采集账号（手机号、会话 Cookie、登录状态） |
| `CrawlRun` | `pc_crawl_run` | 抓取记录（关键词、条数、成功与否、错误） |
| `LLMProvider` | `pc_llm_provider` | 大模型厂商（Key、接口地址、模型、连通耗时） |
| `AIRecommendRecord` | `pc_ai_recommend_record` | AI 任务记录（推荐 / 洞察 / 文案，含结果与耗时） |
| `ApiSource` | `pc_api_source` | 外部 API 数据源（鉴权方式、字段映射、请求体等） |

## 目录结构

```
商品分析平台/
├─ 商品分析平台.exe          # 程序入口
├─ 使用说明.txt              # 面向使用者的说明
├─ data/
│  └─ jobadmin.sqlite3       # 本地数据库（首次启动自动生成）

   ├─ python313.dll 等        # Python 运行时与扩展模块

   ├─ apps/product/migrations# 数据模型迁移文件
```

> `data/` 与 `_internal/data/` 中的数据库、日志、采集导出数据、登录态文件均已加入 `.gitignore`，不随仓库分发。

## 常见问题

**双击 exe 没反应？**
先等 10~20 秒。程序需要解包并初始化数据库，首次启动较慢，之后会快很多。若超过一分钟仍无窗口，查看目录下的 `jobadmin_日期.log`，里面会写明失败原因。

**浏览器没有自动打开？**
手动访问 `http://127.0.0.1:8848/`。

**提示端口被占用？**
说明已有实例在运行，先关闭现有窗口，或在任务管理器中结束「商品分析平台.exe」进程。

**怎么退出 / 怎么备份？**
关闭程序窗口即退出。数据保存在 `data/jobadmin.sqlite3`，复制该文件即完成全部数据备份。

**杀毒软件报毒？**
PyInstaller 打包的程序偶被误报。本程序无联网外发行为，仅在主动使用采集功能时访问唯品会。

## 说明

- 本程序只做本地数据分析与展示，不上传任何数据到外部服务器；唯一涉及外部网络之处是主动点击「采集」时访问唯品会。
- 仓库中不包含数据库文件。运行所需的 `data/jobadmin.sqlite3` 会在首次启动时自动创建。
- 请勿将本地数据库提交到公开仓库 —— 其中可能包含大模型 API Key、采集登录态等敏感信息。
